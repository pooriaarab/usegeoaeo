# geoaeo Brand

geoaeo helps sites become discoverable, quotable, and usable by search engines,
AI answer engines, and agents. It audits a site, reports a score from 0 to 100,
and generates supported discovery artifacts.

## Name and offer

Write the product name as lowercase `geoaeo`. Use `usegeoaeo` only for the
repository or domain. The package is free, open source, and MIT licensed. Do not
imply a paid tier.

Describe the library, CLI, and MCP server as three interfaces to the same
capabilities. Keep their commands and tools aligned with shipped code.

## Audience

Write for builders and teams that want their sites cited by answer engines.
Assume technical curiosity, but explain GEO and AEO on first use.

## Voice

- Lead with the answer or completed action.
- Use concrete nouns, active verbs, and short sentences.
- Name the exact artifact, command, score, or missing check.
- Explain limitations without hedging.
- Avoid hype, filler, padded lists, and invented capabilities.
- Prefer `npm install geoaeo` when showing installation.

## Mark

The mark is a high-contrast rounded square containing a lowercase `g`. Render
it with the foreground and background tokens. Keep its geometry and case. Do
not add gradients, outlines, shadows, or decorative effects.
